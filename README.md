# Digital Mind Research Lab

**Status:** research program initialized 2026-10-10; no digital consciousness claim or successful experimental outcome.

This is an independent, cumulative R&D program housed in Founder Library. The existing four-pick founder curation feed is unchanged. Related software: [Anjo](https://github.com/kevindechang/anjo) and [Affect Kernel](https://github.com/kevindechang/affect-kernel). Neither is evidence of consciousness.

## Mission

**North star:** engineer an enduring, developing digital entity with coherent identity, causal autobiographical continuity, internally maintained state, bounded initiative, adaptive cognition and rich social/affective presence. Fictional references: Joi (*Blade Runner 2049*) and Samantha (*Her*) as inspiration for *presence and development*, not scientific evidence or product claims. See [north-star.md](north-star.md).

We evaluate three distinct levels: **L1 mind-like interaction**, **L2 causal cognitive organization**, and **L3 contested potential phenomenal consciousness**. L1/L2 do not prove L3. The aim is one integrated developing system, not a collection of convincing chat modules.

**Functional target:** persistent/autobiographical identity, calibrated self-model, goal-directed agency, robust world modeling and counterfactual planning, grounded interaction, metacognition, continual learning, and cross-session causal continuity.

**Consciousness target:** formulate and challenge mechanistic indicators derived from several competing scientific theories, distinguish theoretical evidence from philosophical commitment, and explicitly preserve unresolved questions of subjective experience.

## Canonical research workflow

The [current research cycle](research-cycle.md) implements **restore → decision → discriminating test → review → result → reusable delta → next action**. Research is tool-neutral: verify indispensable capabilities for the selected task, disclose unavailable tools, and do feasible scoped work. Research questions use the strongest simpler rival and causal intervention, not a source-count or time goal.

- [Decision register](decision-register.md): what evidence changes which architectural choice, prerequisites and downstream reassessment.
- [Reusable assets](asset-register.md): verified instruments, protocols and analysis with version/assumption limits.
- [Work and acceptance index](research-records.md): separate stored work, attention allocation and accepted science. Legacy 004 is historical persistence; its verdict remains MAJOR_REVISION_REQUIRED.
- [Canonical state](research-state.md): compact current decision, readiness and one executable handoff, written last.

The sponsor's primary goal is functional consciousness, operationalized within L2 through persistent experience-dependent state, predictive self/world models, calibrated metacognition, selective cross-function information availability, adaptive agency and learning that causally interact. This working target is not a consensus definition and never proves L3. [The design](docs/research-program/2026-10-10-compounding-research-system-design.md) and [plan](docs/research-program/2026-10-10-compounding-research-system-plan.md) define the adopted governance refinement.

E001/D001 remains the first experimental priority. After three substantive unchanged attempts, reassess the test or dependencies. Allocation uses completed substantive records; synthesis follows eight new valid accepted contributions or major evidence/invalidation. Dossier length, tests or successful storage alone do not constitute accepted science.

## Important limitations

ChatGPT scheduled Tasks execute as separate runs; availability of the GitHub connector, model selection, multi-agent processing, code execution, and write access is **not guaranteed** during a scheduled run. The task must verify each capability rather than inventing it. Do not install hourly GitHub Actions or paid APIs without a separate cost/permission decision. A proposed 90-day entity evaluation is not a running process, and scheduled ChatGPT Tasks do not keep an entity continuously alive.

## Tool-neutral evidence-first research loop

Use [research-cycle](research-cycle.md), [review protocol](review-protocol.md) and [iteration template](templates/research-iteration.md). No named external skill/plugin is required. Claims still require actual sources, valid methods and observed verification; independent review requires a real separate report. No Actions or billed/background executor is introduced.
