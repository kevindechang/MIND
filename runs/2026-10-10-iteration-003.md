## One question

After the fully identified three-bit XOR world from iteration 002, can we develop a more realistic causal action+commitment instrument without falsely making a graph architecture the assumed winner?

## Evidence triangulation and rivals

- **S010 (AMA-Bench, ICML 2026, peer reviewed):** https://proceedings.mlr.press/v306/zhao26bs.html. Evaluates memory on long action/observation trajectories with causal and state-update demands. Its authors report a causal-graph memory system above their best baseline on their benchmark. This is external task-dependent evidence, not an E001 comparison or proof of graph necessity.
- **S011 (CausalGame, ICML 2026, peer reviewed):** https://proceedings.mlr.press/v306/chen26l.html. Interactive experimental design under confounding/selection/noise; motivates moving E001 beyond deterministic complete diagnostics. No claim about autobiographical memory superiority.
- **S012 (Causal Memory Intervention, arXiv 2026-05, preprint):** https://arxiv.org/abs/2605.17641. Evaluates selecting *useful* memories through interventions rather than semantic similarity alone, but reported conversational answer outcomes must not be equated with causal agent action competence.
- **Rival formal account:** POMDP belief-state and predictive-state representations (already S008/S009) can summarize history for optimal control without an autobiographical graph. A finite optimal sufficient state cannot be beaten in achievable Bayes value when given the same observations and compute assumptions.

## Executed technical artifact (not an AI model trial)

**Local observations:** Python stdlib unittests 10/10 PASS; 100/100 complete-diagnostic seeded worlds give the same action and reward using ground truth vs observation-only influence matrix; 419 of 1,000 paired synthetic worlds change optimal plan when the last earlier commitment is removed. These are generator/instrument properties, not trained agent outcomes, preregistered estimates or evidence of a whole digital mind.

**Critical challenge:** Once all seven intervention effects are observed, a small lookup table and the prior goal records *perfectly suffice*. The graph has no attainable accuracy advantage under these observables. The experiment is therefore a testbed for causal memory integration and event handling, not a decisive architecture benchmark. Missing data currently cause a rejection rather than a possibly biased oracle score.
