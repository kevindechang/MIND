## The information collision and a tight bound

Let E be the complete sorted `source_events` returned by `factual`, G the initial `causal_links`, C the compiled `availability` feature and A the action. In this implementation C is built from (E,G), while the linked policy also uses (E,G). Setup provides G independently of E; **G=g(E) is not an admissible assumption**.

The prospective probe calls the existing API twice:

| World | Events E | Dependencies G | Linked action | Compact action |
|---|---|---|---|---|
| Connected | goal uses sensor; array_power unavailable; clock tick | goal→sensor→array_power | DEFER | DEFER |
| Disconnected | **exactly the same E** | goal→sensor | SCAN | SCAN |

Both arms physically undergo SIGKILL (exit -9) and new-process ledger-only readback. The observed source rows are equal, while both readers' actions differ. This is within the existing setup API, not a target-code mutation or an off-domain semantic interpretation.

**THEORETICAL, audit derivation:** suppose these two worlds occur with equal probability, the required binary actions are those prescribed by the fixture's world rule, and a rival receives only E, no world identifier, graph, compiled feature or other correlated signal. If it chooses DEFER with probability q(E), its accuracy is `(q(E) + 1 - q(E))/2 = 1/2`. Any deterministic or randomized events-only policy has expected error 1/2; the graph-aware fixture attains accuracy 1 on this pair. This is an exact conditional two-world bound, not an empirical population estimate, statistical significance test, new information-theory theorem, or general proof that graphs improve cognition. Under unequal known priors the maximum accuracy is the larger prior mass; with additional observations the bound need not hold.

The contrast shows **information omission**. It cannot establish a representational advantage because the two competitors' inputs differ. If the intended history H instead includes initial dependency observations, use `H=(E,D)` where D contains those observations; a compact or transcript rival may then compile, retain or reconstruct G. Changing H changes the admissible comparison and must be explicit.

Within a fixed seeded world, deleting G does causally alter the hardcoded linked reader's action. That narrow intervention is reproducible and legitimate. But C remains a descendant of the prelesion G, so deleting the table does not remove all stored consequences of dependency information. Diagram: `(E,G)→C→compact action`, and `(E,G)→linked action`; surgery cuts the linked route while preserving the compiled route. A successful compact action identifies an alternative route in this fixture, not autobiographical representation uniqueness or a fully matched intervention across architectures.

## Two boundary counterexamples

**OBSERVED — compact refresh:** start with a public graph sensor→array_power and an unrelated greenhouse outage; compile the availability feature from those same graph/event rows. Both policies initially SCAN. Append a new, public array_power outage, commit, close and reopen the SQLite connection, and read both policies. Linked now DEFERs; compact still SCANs. The extra public event is visible to both readers, but compact lacks a feature-update rule. This shows that its fixed initial feature is not demonstrated to be an update-closed predictive state for a future evidence stream. It does **not** show an unavoidable graph advantage: a fair compact controller can refresh its feature or store dependency information, with its costs accounted for. This probe extends the frozen one-step domain; it does not invalidate the original compact tie or claim a failed preregistered prediction. This particular probe reopened a connection; it did not perform a process kill.

**OBSERVED — edge semantics:** in a non-outage-connected setup, the linked reader SCANs. Repoint an edge tagged `relation='unrelated'` from the irrelevant clock/light pair to goal/array_power while retaining that tag and all event rows. It then DEFERs, because `_linked_resources` reads only `(effect,cause)` and ignores relation. This is an out-of-original-seed-domain robustness probe. The original sham remains valid for its unreachable endpoint placement; it tests topological irrelevance, not semantic filtering. Specify whether the contract is untyped reachability or typed causal semantics before interpreting semantic lesions. This closure calculation does not establish that it identifies structural causal counterfactuals from a learned causal model.

## Literature contribution and strongest opposing account

The accompanying [primary-source methods memo](../docs/research-notes/2026-10-11-E100-causal-lesion-identifiability-sources.md) gives source versions, inspection depth, assumptions, limitations and contrary evidence. It is a targeted narrative methods analysis, not a systematic review or a replicated paper result.

Our inference is conditional: sufficient-state alternatives require sufficiency for the registered intervention/query domain and an update rule for future permissible observations. Existence of a mathematical predictive state does not establish learnability, finite-budget parity or robustness outside that domain. A rich graph could still be practically useful under new interventions, restricted memory, correction demands or compositional transfer. Conversely, acute ablation effects can reflect the chosen implementation's dependency and transient disruption; recovery and matched-state alternatives remain live rivals. The observed two-world collision sharpens the prerequisite: first show that the rival has the same information, then evaluate whether its representation can use it.

## One next discriminating experiment — proposed, NOT RUN

**Question:** after identical public dependency observations and an unexpected resource outage, does a learned causal representation improve future planning/repair over a refreshed compact state under the same lifecycle resources? Strong rival: an adaptive compact predictive/belief controller with explicit update and reconstruction, not the current unrefreshed cache. Include transcript/retrieval if feasible, without depriving it of D.

Before any scored trial, freeze a separate held-out distribution of dependency topologies, alternative paths, outages and restorations, public observation interfaces, private world transition rules, resource ceilings, randomization, split hashes, costs, practical margin, uncertainty analysis, exclusions and stop rules. Distinguish three interventions: remove the graph cache with full history available (reconstruction); sever the reader route while cached state remains (access); delete the same dependency evidence and all derived state across representations (information knockout). Include sham cuts and no-event controls. Score actual downstream world outcomes under future actions, rather than agreement with the linked policy. Report immediate and recovered endpoints separately; restart each arm using only its own persisted ledger.

**Proposed estimand:** paired difference in held-out cumulative world utility minus measured lifecycle computation cost, including ingestion, construction, storage, invalidation, refresh, reconstruction, retrieval and acting. Numeric effect margin, sample/precision plan and conversion from compute to cost are deliberately unfrozen: this is not a registered efficacy design. A graph win must survive a fair updating rival and useful-world endpoint; a precise tie favors simpler machinery in the tested domain; an imprecise null remains inconclusive. If equal admissible histories imply different evaluator labels, stop and repair the observation-validity defect before scoring.

**Falsifier of our central collision:** show a permitted field in the declared E-only interface that distinguishes the two worlds, or show the same required action is correct in both under an independently specified world transition/reward rule. That would invalidate this two-world bound's premises. Merely giving one rival G or C changes the comparison rather than disconfirming it.
