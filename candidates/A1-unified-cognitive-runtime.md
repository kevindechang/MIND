# A1-CANDIDATE — Unified Cognitive Runtime (unapproved research design)

**Status:** SPECULATIVE / NOT IMPLEMENTED / NOT SELECTED / NOT PROOF OF MIND OR CONSCIOUSNESS.
**Source:** R002 contributor mandate, extracted critically in ../reviews/2026-10-10-R002-ambitious-agent-mind-extraction.md.
**Canonical architecture:** A0-PROPOSED remains unchanged. This file is an explicit *competing* design candidate.

## Research challenge

Can a single persistent artificial entity achieve genuine causal continuity and developmental competence by integrating internally generated maintenance, self/action attribution, long-term memory, reusable skill induction, predictive world/self modeling and regulated adaptive state? What components, if any, outperform an equivalently resourced simple controller?

The target is a coherent developing artificial individual (L1/L2), not an impression of continuous subjective life (L3 remains unresolved).

The diagram names **research interfaces**; it does not prescribe one event bus, knowledge graph, LoRA method, transformer or always-on runtime. Foreground interaction and background maintenance are independently optional; compare true background execution with on-demand reconstruction. Logs are evidence of compute/state transitions, not subjective experience.

## Seven proposed components and ablation contracts

1. **Persistent causal memory:** action, expected result, observed result, correction, valid time, recording time and provenance. Compare minimal summaries, retrieval and non-destructive time-aware storage (E001). No mandatory Conway/Graphiti stack.
2. **Self/world action attribution:** predicted effects of internal/external actions ("efferent copy") and innovations separating self-caused from independent changes. Compare plain event logs and shuffled action-outcome traces (H010/E002).
3. **Causal self-model:** track goals, past commitments, epistemic limits, own tool capabilities and revision history. Test intervention on confidence, skill impairment and commitment conflicts (H002/H007/E900).
4. **Bounded internally initiated regulation:** check stale commitments, contradictions, unresolved uncertainty and resource limits. Benchmark actual state utility vs scripted cron or demand-triggered cleanup (H005/H008/E002).
5. **Impasse-to-skill learning:** identify repeatable failures, generate a bounded candidate rule/procedure, validate against hidden sandbox tests, version and roll back; never deploy arbitrary generated code or contact services without approval (H011/E003).
6. **Multi-timescale plasticity:** factual updates, causal graph edits, verified procedural policies, optional adaptive latent state, experimental adapters/weights. Evaluate transfer, forgetting, identity drift, deletion and cost at equal budgets (H012).
7. **Adaptive attention / global broadcast (optional):** compare shared workspace with point-to-point coordination, direct single-model reasoning and recurrent integrated substrates under matched compute. Causal receipt logging is instrumentation, not consciousness proof (H003).

## Alternative architectures that must compete

- S0: reactive state-reset LLM with same observation/tools/budget.
- S1: retrieval-only, scheduled maintenance and static personality; no learned causal structure.
- S2: simpler persistent finite-state or model-based policy and deterministic memory/procedural rules.
- S3: recurrent predictive-state agent without separately named workspace/self memory.
- S4: world-model/active-inference or artificial-life/embodied candidate with matched interaction budget.

An integrated candidate cannot win merely by consuming more context, GPU time, tool calls or human labor. Test causal differences under ablations and unseen interventions. Hold out transition mechanisms, not just wording.

## Discriminative development milestones

**D0 (before implementation):** state specification, action oracle, alternative model classes, precommitted resource parity and safety review. **D1:** E001 memory mechanism G0→G2. **D2:** E002 actual self-initiated maintenance + efferent attribution vs controls. **D3:** E003 procedural compilation with true novel transfer after process reset. **D4:** multi-timescale learning with retention and privacy tests. **D5:** E900 staged whole-entity longitudinal integration. No architecture is promoted by a passing *single* component test.

## Frontier candidates, not a fixed 2026–2028 promise

- Grounded latent hierarchical predictive models (JEPA-family or other) that can plan without having to verbally narrate every step.
- Event-driven/recurrent/neural/neuromorphic computation for high-efficiency state maintenance.
- Theory-discriminative consciousness research and substrate/embodiment objections with strict L3 epistemic humility.

**Promotion criteria:** Evidence from a preregistered, reproducible, matched-budget, ablation-rich comparison demonstrates meaningful integrated causal gain (E900), with cost, privacy, consent and robustness acceptable. A1 can be rejected; A0 remains the architecture register until an evidence-backed decision.
