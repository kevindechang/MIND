# Digital Mind work record — compounding template

- Stable unique work ID/path (checked against live main):
- Kind: GOVERNANCE_CHANGE / EXPLORATORY_CHECKPOINT / RESEARCH_NOTE / INSTRUMENT_VALIDATION / AGENT_COMPARISON / SYNTHESIS:
- Scientific verdict: EXPLORATORY_CHECKPOINT / RESEARCH_NOTE / SCIENTIFIC_ACCEPTED / MAJOR_REVISION_REQUIRED (UNKNOWN for unaudited history; NOT_APPLICABLE for governance):
- Date / actual trigger / source main SHA / previous work record:
- Capability check for selected task; no named framework prerequisite; missing indispensable inputs and feasible alternatives:
- Tools/model/execution/source retrieval/clock/GitHub/reviewer capabilities: AVAILABLE / UNAVAILABLE / UNKNOWN:
- Actual methods/tools used / reviewer identity and dispatch evidence, or SELF-REVIEW_ONLY / REVIEW_NOT_DONE:
- Stream / gate / blocker / decision ID / contribution ID if seeking acceptance:
- Start/end/duration only if observed, otherwise UNKNOWN:

## PLAN — before work

- Decision, bounded claim, outcome → action mapping:
- Prerequisite decisions/pivotal evidence, exact version, freshness and stale dependencies:
- Strongest viable simpler rival, distinct prediction, falsifier:
- Estimand, permitted observations/oracle, confounds and negative controls:
- Primary methods/counterevidence to inspect; source dependence:
- Asset ID/version reused; assumptions applicable? Changes/revalidation:
- Controls/ablations, lifecycle resources, held-out mechanism families and frozen analysis if scoring:
- Approval/ethics/tool dependencies, smallest deliverable and interruption checkpoint:
- Prior attempts / three-attempt reassessment if no uncertainty/decision/gate changed:
- Selection rationale and attention-allocation exception, if applicable:

## Actual research and execution

- Source IDs, direct primary links/dates/type, actual methods/results inspection depth:
- Claim labels OBSERVED / PAPER-REPORTED / THEORETICAL / PROPOSED / SPECULATIVE / UNKNOWN:
- Exact code/protocol/environment version, commands/logs/seed accounting/costs:
- PROPOSED / SIMULATOR_TESTED / AGENT_EXPERIMENT_EXECUTED / NOT_EXECUTED or BLOCKED_ON_EXECUTION:
- Results/uncertainty/deviations, strongest contrary finding and alternative explanation:
- Dossier/experiment section changed, or honest reason no change warranted:

## Review, decision and reusable delta

- Scientific quality and review rubric result / actual independent review provenance:
- Accept / revise / reject / defer; bounded supported scope and confidence:
- Gate exit criteria met? No promotion from scaffolding alone:
- Null/negative interpretation; never infer equivalence from nonsignificance:
- Changed claim/evidence → direct/transitive dependent decisions flagged or restored with justification:
- Asset added/reused/revalidated and exact limitations:
- L1/L2/L3 separation; E900 observable and proposed cross-function intervention:
- Attention eligible? Distinct accepted contribution eligible? Justification and ID:
- Synthesis trigger/milestone IDs under research-records; governance counts toward neither:

## Persistence and one executable handoff

- Artifact/index/decision/asset commit, then state LAST; final read-back SHA externally/later:
- Collision/concurrency check, interrupted publication reconciled once, or NOT_COMMITTED full delta:
- Precisely one next action: inputs/version, required capability, deliverable, stopping condition:
- Remaining dependency/tool/ethics blocks:

Apply [research cycle](../research-cycle.md), [scientific gate](../research-quality-gate.md), [publication standard](../publication-standard.md) and [work accounting](../research-records.md). A committed work record is not automatically accepted science.
