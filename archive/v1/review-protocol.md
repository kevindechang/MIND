# Adversarial scientific verification rubric v1

Record `review_mode = INDEPENDENT_SUBAGENT_VERIFIED | SELF-REVIEW_ONLY | REVIEW_NOT_DONE`. A self-critic prompt is never independent review. Skills can be cited as **invoked** only when actually accessible and read.

Before advancing any gate or making any strong claim, inspect:
1. Target separation: behavioral L1 vs mechanistic L2 vs theory-specific consciousness indicators vs unresolved phenomenal L3. No self-report as proof.
2. Primary sources: URLs, dates, peer-review or preprint, method/abstract distinction, disconfirming evidence.
3. Decision relevance: does the test distinguish the hypothesis from the strongest simpler rival? If not, downgrade.
4. Identification: causal graph/intervention, delayed events, hidden confounders, exposed observations, oracle secrecy.
5. Fairness: matched information, model, calls, tokens, compute, tools and retrieval where possible; disclose inequalities. Compare compact belief/predictive state and transcript baselines.
6. Preregistration: controls, exclusions, seeds, effects, intervals, multiple comparisons and stopping before scored tests.
7. Execution provenance: source file != tested; local deterministic simulator != LLM agent; tests/logs checked, no invented outcomes.
8. Longitudinal validity: accelerated simulation != real 90-day E900; one module != digital mind.
9. Tool honesty: skills/subagents/runtime measured or explicitly unknown; GitHub commits read back; no hidden billed actions.
10. Ethics: human consent, privacy, truthful persona, autonomy boundaries, possibility of artificial welfare uncertainty.

11. Compounding validity: decision ID/outcome-to-action map, reused asset version/assumptions, direct/transitive prerequisite freshness, E900 causal coupling and bounded scope.
12. Accounting: kind vs acceptance, distinct contribution ID, no legacy backfill, no double count on amendment/recovery; allocation and synthesis are separate.
13. Null interpretation: insufficient precision/nonsignificance is not equivalence; use prospectively frozen practical margin and uncertainty.

CRITICAL = fabricated experiment, source, sentience attribution or unsafe action; IMPORTANT = absent pivotal controls/preregistration/readback. Do not promote claims with CRITICAL/IMPORTANT unresolved. Missing independent reviewer → SELF-REVIEW_ONLY, with no implied objectivity.
