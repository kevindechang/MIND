# Digital Mind work record

Use the [current compounding template](research-iteration.md) for all new work. This short entry point supersedes the older numbered-iteration template; preserve existing historical runs.

- Stable unique ID, kind and scientific verdict are separate.
- Verify relevant sources/execution/write/reviewer capabilities; no external framework prerequisite.
- One ready decision, strong rival, falsifier and outcome → action.
- Exact asset reuse/assumptions; dependency freshness and invalidation propagation.
- Actual source depth, execution/logs/resources and reviewer provenance.
- Bounded result, uncertainty, L1/L2/L3 and E900 intervention.
- Artifacts/index first, state last, verified persistence; one executable next step.

Counters and allocation follow [research-records](../research-records.md), never old filename numbering.
