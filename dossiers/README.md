## Status and promotion

- **SEED:** scope, mechanism map, a bounded set of evidence and explicit gaps. No systematic-review claim.
- **DEVELOPING:** multiple rigorous analytical updates, resolved causal definitions, adversarial source comparison, cross-linked experiments; still limited by evidence coverage.
- **REVIEWED:** transparent search/inclusion methods or explicitly scoped review, actual independent audit where available, traceable original sources and formal methods. This is an internal status, *not journal peer review*.

A dossier has four synchronized files: `synthesis.md` (argument), `literature-matrix.md` (provenance), `competing-theories.md` (falsifiable contrast) and `open-questions.md` (research allocation). Each meaningful update records sections changed, source and experiment IDs, epistemic status and version notes. Missing primary full texts must be admitted. Source maps must never silently claim systematic or PRISMA compliance.

Use [publication standard](../publication-standard.md) and [template](../templates/living-dossier.md). The next hourly iteration may have nothing to add to a particular dossier; in that case publish a clearly scoped technical artifact and honest run record instead of padding.
