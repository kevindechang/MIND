## Evidence and experiments

Label claims OBSERVED / PAPER-REPORTED / THEORETICAL / PROPOSED / SPECULATIVE / UNKNOWN; preserve E0–E3 provenance grades. Author-supplied R001/R002 proposals are not independently verified. Use primary URLs/versions, actual inspection depth and strongest counterevidence. Philosophy is not empirical validation; no source-count or word/time quota implies rigor.

Preregister scored comparisons, randomization, resources, controls, ablations, uncertainty, exclusions and stop rules before trials. Version amendments; do not rewrite predictions after data. Record actual commands/logs/costs. Never mark EXECUTED without observed execution; simulator tests are not agent outcomes. Real module code uses TDD; independent review requires a real distinct invocation, otherwise SELF-REVIEW_ONLY.

Dossiers and experimental reports carry science; runs carry transactions. Update intellectual artifacts only for substantive analysis, not padding. The scientific quality gate governs acceptance independently of storage/testing. New architecture adoption, production behavior, data access, spending and expanded autonomy retain approval boundaries.
