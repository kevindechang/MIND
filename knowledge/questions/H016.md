**Hypothesis.** H015 found that a value-of-information organ, fed by an efference-style record and routed to action, improves
control on the uniform prior (C079-C082). Its estimate of what a probe is worth is built from an approximate prior, and that
estimate is miscalibrated under other observation models. Under censored probes it over-probes and loses utility (C083). The
hypothesis: exact inference over a generic hypothesis space of causal graphs gives a calibrated value of information, so the
same routed organism does no harm under censoring or the skewed prior, and keeps its gain on the uniform prior.

**Exploration that motivated the claims (dev seeds 0-7, 1500 episodes; not evidence).**

1. *The approximate prior is the source of the miscalibration.* A diagnostic gave the routed organism the exact posterior over
   the workshop's eight graphs (privileged; not an organism). With the same one-step rule it was calibrated on all three
   variants: utility gains +0.22 (dev), +0.01 (censored), +0.02 (skewed). H015's fixed route lost 0.08 on censored
   probes and gained 0.03 on the skewed prior. The calibrated count-prior version lost 0.06 on the skewed prior.
2. *Scaling the route by value alone does not fix it.* Scaling the bonus with a censor-aware value trades dev gain against
   censored harm. The best setting by worst case still loses on skew. Carrying the value as salience (the principled version)
   gives the same trade-off.
3. *Learning the trust in a proposal from its TD error fails.* Trust learned this way collapsed probing to 0.04 to 0.07 per
   episode. A probe's cost arrives on the step where it is taken, and its benefit arrives later, so the TD error is negative
   for exactly the actions whose value is delayed.
4. *An unbiased learning phase does not fix the approximate prior.* Forcing random probes for 200 episodes, so that the counts
   are not conditioned on earlier results, did not change the variant dependence. Adaptive sampling is not the main cause.
5. *The generic posterior reproduces the calibration.* Exact inference over all 25 labelled directed acyclic graphs on the
   three nodes, uniform prior, with the censor-aware value, the salience carry and the value-scaled route, gave: dev utility
   -1.39 (plain -1.68, regret 0.27), censored -1.69 (plain -1.67), skewed -1.48 (plain -1.46). The repo implementation reproduces
   these numbers exactly.

**Design choices, fixed before registration.** Hypothesis space: the 25 labelled DAGs on three nodes, with the reach semantics
of the world (a node reaches itself and every node it points to, transitively). Uniform prior. Probe cost 0.25, the
workshop's cost (domain knowledge). Censor rate learned from the organ's own probe results, with Laplace smoothing. Value
carried as salience at 4.0 per unit of net value. Route scale 4.0 (value_bonus), chosen on dev seeds 0-7 over the unscaled route (value_bonus 0); not tuned further.
The held-out seeds are drawn from the drand beacon after the claim commit is pushed.

**Margins.** 0.15 utility over plain on the uniform prior (C085), where exploration gave +0.29. Equivalence within 0.05 on the
censored and skewed variants (C086, C087), where exploration gave -0.02. 0.05 for the calibration comparison against H015's
fixed route on censored (C088), and against the approximate count prior on dev (C089). For C088 exploration gave +0.06; for
C089, +0.10.

**Limits, stated before any held-out run.**

- The hypothesis space is supplied. The organ knows that there are three nodes, that a graph is a DAG, and what reach means
  (the world's rule). It does not know the eight forward graphs, and it has a uniform prior over all 25 DAGs. Learning the
  hypothesis space itself is an open problem.
- The value of information is a one-step (myopic) rule. The Bayes reference plans two probes ahead, so the gap that remains
  to it (regret 0.27 on dev against 0 for Bayes) is partly non-myopic planning.
- The payoff model is supplied. The XOR composition, the penalty, the probe cost and the reach semantics are the workshop's.
- Three nodes only. The claims say nothing about larger structures.
- The efference record is still an architectural assumption (H015).
- No correction for multiple comparisons across C085-C089.

**Strongest rivals.** The approximate count prior with the same route (C089); H015's fixed route (C088); the plain organism
(C085-C087); and the privileged Bayes reference (`rival:bayes`), which is a ceiling and is not required to be beaten.
