**Hypothesis (v1 H002).** An explicit model of one's own capabilities and uncertainty improves calibration and self-correction after hidden capability changes, beyond more compute or a static self-description.

**v2 operationalisation.** The `self_model` organ fits P(success | action, broadcast context) online and reports forecasts that are scored against public outcomes (Brier). Its standing simple rival is a per-action success table (the transcript rivals' forecaster: an exponential average of each action's public outcomes). C017 and C018 test it on the shared organism, scoring the self-model and the success table on the SAME events (`calib_gain`): the self-model is better both when outages are announced and when they are silent. The first-round claims C007/C008 compared each agent on its own action stream; the v2 review showed that confounds calibration with behaviour (C008's "tie when silent" was an action-mix artifact), so both were retired.

**The stronger rival is not yet tested.** v1 PR #15 showed that a compact *event-aware* controller, which reads the public outage announcements as well as outcomes, reproduces a hand-written Day 3 "self-model" exactly (72 of 72 states). The v2 success table does not read announcements. In `outage/silent` there are none, so there the table is #15's rival and C018 answers it. In `outage/dev` the table is weaker than #15's rival: C017's margin may come entirely from reading `alert=`, which an announcement-aware table would do as well.
