**Hypothesis (v1 H002).** An explicit model of one's own capabilities and uncertainty improves calibration and self-correction after hidden capability changes, beyond more compute or a static self-description.

**v2 operationalisation.** The `self_model` organ fits P(success | action, broadcast context) online and reports forecasts that are scored against public outcomes (Brier). Its standing simple rival is a per-action success table (the transcript rivals' forecaster: an exponential average of each action's public outcomes). C017 and C018 test it on the shared organism, scoring the self-model and the success table on the SAME events (`calib_gain`): the self-model is better both when outages are announced and when they are silent. The first-round claims C007/C008 compared each agent on its own action stream; the v2 review showed that confounds calibration with behaviour (C008's "tie when silent" was an action-mix artifact), so both were retired.

**Announcement-aware table (C041, K13).** v1 PR #15 showed that a compact *event-aware* controller, which reads the public outage announcements as well as outcomes, reproduces a hand-written Day 3 "self-model" exactly (72 of 72 states). The v2 success table does not read announcements. In `outage/silent` there are none, so there the table is #15's rival and C018 answers it. In `outage/dev` the table is weaker than #15's rival. The announcement-aware scorer is that same table, updated by each public `alert=down` / `alert=up` as one extra scan observation at the table's own rate (`calib_gain_alert`). K13 checks it matches the plain table wherever no announcement is emitted. C041 asks whether the self-model still beats it by C017's 0.008. Dev 0.010 [0.006, 0.014] and the first sealed held-out run 0.007 [0.004, 0.011] both cover 0.008, so the margin is neither cleared nor closed. Those held-out seeds are spent.

**Silent capability shift (C042, C043).** `outage/shift` steps P(scan success) from 0.9 to 0.15 at episode 60 and emits no announcements, so the two tables are the same rule. C042 asks whether the surprise broadcast speeds control re-adaptation: acute reward advantage of the intact organism over `self_model.surprise=2` greater than 0.5 in episodes 60–74, and the late gap (episodes 100–119) inside ±0.5. The late gap is inside the band. The acute advantage is not: held-out intact−lesion is −0.937 [−1.482, −0.392]. C043 asks whether the self-model's same-event advantage over that shared table is larger acutely than after recovery, by more than 0.004. Held-out acute minus recovered is −0.015 [−0.018, −0.012]: the table is ahead in the acute window and the two forecasters meet once recovered. PR #25's compact filter remains an off-substrate exploration, not a sealed scorer.
