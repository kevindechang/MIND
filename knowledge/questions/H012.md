**Hypothesis (v1 H012, from R002).** Learning at several timescales (state, causal memory, procedures, optional weights) improves durable transfer versus any one layer. v2's kernel already supports mid-life lesions, so acute-versus-recovered deficits are measurable.

**What C060 measures.** One vigil life switches variant mid-life: dev, then long, then dev. `@160:freeze:policy` stops policy updates at the first long episode. The sealed test asks for an acute kept deficit above 0.10, an intact recovery above 0.10, a frozen-policy recovery inside ±0.10, and a return to dev no worse than 0.10 below each arm's own pre-switch window. `rival:window8` (same TD learner, last eight raw observations, same public stream) must sit more than 0.50 below the organism before the switch, and its own recovery must lie inside ±0.10. Its acute deficit and immediate return are estimated and do not decide the verdict. On the sealed seeds the composite is inconclusive: frozen recovery was +0.077 [+0.032, +0.121], so the upper end crosses +0.10. The deficit, the intact recovery, and the return bounds held on those seeds. Do not edit C060. A successor needs a new id. No organ was added. Memory and goals reset each episode; this switch did not show a loss large enough to warrant a second durable timescale, and it also did not show that recovery without policy updates is smaller than 0.10.

**Not registered, dev seeds only.** On seeds 0-15, outage dev to silent and back gave an organism acute reward deficit of +1.695 [+0.914, +2.476], above the 0.5 outage bar, but recovery +0.446 [-0.772, +1.665] and the return contrasts straddled ±0.5, including the return versus a life that stayed on dev (+0.092 [-0.431, +0.622] in the last window). Those intervals are exploration, not a record. A within-episode A-B-A world on `contrib/h012-switchback-interference-20261011` is design-only (no claim, no record, stub rival). `contrib/h012-timescales-mac` is not on the remote.

**Scope.** This organism in these worlds. L2 causal organisation, not phenomenal experience. The parent question stays open until a same-cue reversal is measured.
