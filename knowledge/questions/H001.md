**Design status (2026-10-12).** `mind/organs/causal.py` (opt-in `+causal`) is a late organ: the kernel's new `late` phase
(`mind/kernel.py`, `Organ.late_propose`) lets it bid after learning from the tick, so the decision on the tick that shows a
probe result can use it. It learns only attended contents: `fx` probe results and `want` commitments. Its composition is a
supplied payoff model: XOR of reach sets with the workshop's penalty. The eight graphs stay hidden, but the scoring rule is
built in, so this tests the supplied model, not causal discovery (see C070's docstring). Compact control: `causal.derive=0`
proposes a constant `pad` where the recommendation would be (rival `compact`, C071). Sham: `causal.sham=1` randomises only the
recommended plan (C073). `capacity=inf` removes the workspace bottleneck (C074).

**Dev findings that bound what the claims can show (exploration, not evidence).** (1) A probe result is attended on the tick
it is shown in only a minority of episodes: a feature the policy has not learned to use (relevance 0) loses to relevance-boosted
features, and the rate matches the workspace's exploration rate (0.15). (2) When the recommendation exists, the policy follows
it 32% of the time early and 77% late; late, its payoff equals the recommended plan's. (3) The recommendation exists in roughly 7%
of episodes, so the organ can change few decisions. Predicted effects are therefore small, and a null result is the expected
outcome of this design.

**Registration.** Margins came from the research plan (0.15 for the held-out skewed transfer, 0.10 for the rest) and were not
set from dev data. Each claim is decided by its own bootstrap interval, with no multiplicity correction across C070–C074.

**Hypothesis (v1 H001).** A structured memory that links experiences to their causal consequences changes later action under partial observation, beyond transcript replay and beyond a compact sufficient belief state.

**What v1 established (ported as claims L04–L07):** in the E001 three-node family a belief over 7 reachability classes is sufficient (L04), informative censoring and priors move that belief (L05, L07), and adaptive probing is worth exactly 7/120 in the v0.4 setting (L06). So any "causal memory" advantage must come from budgets, learning speed, transfer or misspecification — never from information a compact Bayes state lacks.

**What v2 adds.** The `workshop` world runs the E001 setting as a learning task with the v0.4 dynamic program as its exact optimum (K04). The plain organism ties the reactive transcript rival (C011) and sits far from that optimum (C012): a generic learner does not discover the value of probing. That gap is the measurable target for a causal organ.

**Strongest rival:** `rival:bayes` (privileged, the ceiling), and any compact learned belief state. A causal organ that wins only because it was told the hypothesis family is a by-construction result and must be labelled as such.
