**Hypothesis (v1 H001).** A structured memory that links experiences to their causal consequences changes later action under partial observation, beyond transcript replay and beyond a compact sufficient belief state.

**What v1 established (ported as claims L04–L07):** in the E001 three-node family a belief over 7 reachability classes is sufficient (L04), informative censoring and priors move that belief (L05, L07), and adaptive probing is worth exactly 7/120 in the v0.4 setting (L06). So any "causal memory" advantage must come from budgets, learning speed, transfer or misspecification — never from information a compact Bayes state lacks.

**What v2 adds.** The `workshop` world runs the E001 setting as a learning task with the v0.4 dynamic program as its exact optimum (K04). The plain organism ties the reactive transcript rival (C011) and sits far from that optimum (C012): a generic learner does not discover the value of probing. That gap is the measurable target for a causal organ.

**Strongest rival:** `rival:bayes` (privileged, the ceiling), and any compact learned belief state. A causal organ that wins only because it was told the hypothesis family is a by-construction result and must be labelled as such.
