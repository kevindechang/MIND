**Hypothesis (v1 H007).** An agent whose goals, self-model, memory and world model are causally linked shows adaptation and intervention-resilience beyond independent modules.

**v2 operationalisation: the integration atlas** (`python -m mind atlas`). For every organ × competency in every world it estimates the lesion effect. Integration is visible as (a) *cross-function* effects (an organ reliably affecting a competency it was not designed for) and (b) *degeneracy* (pairs whose joint lesion hurts more than the sum of singles, i.e. mutual backup). Claims C002–C004 (context-dependent necessity and memory/goals degeneracy) and C016 (Holm-corrected integration: distinct organs, curated metrics, same-stream calibration) test it. C009 and C013 remain inconclusive; C010 and C014 were retired after the v2 review (action-mix confound; cells counted as organs, no multiplicity control).

**v3 (2026-10-11): lesion effects are not information flow.** A lesion changes behaviour, and each arm is scored on its own events. Fixed-behaviour *shadows* (`mind/shadow.py`, exact by K09) re-run the self-model on the logged stream with one organ's contents dropped or shammed, so its informational dependence is measured with every event held fixed.

* C016's two calibration cells (memory and goals → vigil.calib_gain) are mostly behaviour (C030). Memory's contents make the self-model slightly *worse* at fixed behaviour. They are informative (real beats a matched sham), but carrying their features costs more. Goals' contents explain about a tenth of their cell. For goals, almost the whole cell is the success table's response to a changed event mix; the table sees no contents at all.
* A self-model cut off from every other organ shows the same kind of cell (C031). The atlas's cross-function criterion is not a valid integration test for metrics scored on behaviour-dependent events.
* Measured at fixed behaviour, integration is real but small. Memory's and goals' contents inform the self-model (C032, Holm, sham-controlled), and one memory content serves both control and metacognition in silent outages (C033).
* Integration also costs. The self-model's broadcast misleads the policy in vigil (C034). See [H014](H014.md) on consumer-side selection.
* C013's successor C035 finds the self-model irrelevant to workshop control within ±0.05 utility. On C013's own sealed seeds the same contrast reads +0.059 [+0.023, +0.094]. Pooled over 80 seeds it is +0.014 [−0.002, +0.031], so a small effect below the margin is not excluded.

**Strongest rival** for any integration claim: a modular system with the same behaviour. A valid integration estimand must read zero for it (C031 is that negative control).

Lineage: E900 cross-module edge ablations (archived proposal), Anjo spec §16 ("a function counts only if removing it changes behaviour"; the shadows add the converse: a content counts for a consumer only if removing it changes the consumer at fixed behaviour).
