**Priority rule:** for what Anjo proposes to ship, consult the live Anjo repo first; this pinned Oct 2 snapshot is for reproducible comparison, not an automatically up-to-date product directive. For what MIND should conclude scientifically, evidence, stronger alternatives, experiments and MIND's quality gate outrank *all* architectural proposals, including Anjo's. If a later Anjo decision conflicts with the snapshot, cite the new source SHA and update the source map only after verified review.

**Anjo I1–I12:** product invariants in the Oct 2 source (§3). They concern selected-target/source provenance; selection ≠ execution ≠ benefit; stale-job fences; immediate correction/deletion invalidation; anti-self-evidence; source/interpretation separation; idempotence; foreground isolation; preference/consent/safety precedence; account isolation; cleanup independence from feature switches; and honest processing receipts. These are Anjo's proposed release/test obligations, **not** evidence of MIND cognitive efficacy.

**Persistent Mind PM3/PM4 mapping:** MIND H001/E001 challenges causal autobiographical memory against *sufficient belief-state* and retrieval rivals; W2/E002a challenges endogenous/background metacontrol against **learned external** schedulers. MIND can help define experiments; it must not silently install a second Anjo scheduler/memory authority. Anjo's snapshot–compute–commit and version/epoch fences are product contracts to respect for any later transfer.

**VERA protocol precision:** the available Oct 9 monograph contains an explicit *research evaluation proposal* (notably §11–§14 and §13); a separately frozen named **"VERA-1 coverage-equivalence protocol" has NOT been verified in the retrieved repository/file sources**. Do not invent one, or equate Anjo spec I1–I12 with a nonexistent experiment. If a separate VERA-1 document is later supplied, register its exact path, authority, revision, comparison arms and effect/coverage gates before claiming alignment.

**Permitted source uses:** compare hypotheses, cite dated constraints, design falsifiers. **Not permitted:** treating draft author's preferred solution as observed efficacy; copying private production data into MIND; asserting shipped Anjo behavior from proposed specifications; conflating source count with full-paper review. The R001 "must-not-import-as-facts" filter is mandatory.

**Version hygiene:** embedded snapshots are immutable evidence as of the stated versions. Corrections to their *interpretation* belong in analysis/reviews, not silent edits of the source copies. Track newer canonical Anjo revisions by their exact commit, source path and status. Keep conclusions source-labeled and contradictable.
